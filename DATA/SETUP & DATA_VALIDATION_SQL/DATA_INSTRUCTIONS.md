## Data Instructions ## 

The source dataset is hosted on Kaggle:

https://www.kaggle.com/datasets/shrutimehta/zomato-restaurants-data

## Setup

1. Open the original Kaggle dataset page.
2. Review its licence and terms.
3. Download the dataset based on your choice. 
4. Place the permitted source file in your local data directory.
5. Follow the setup instructions in the project documentation.
6. Most importantly keep the raw data in the original file and use the copied file to edit and clean.

The raw dataset is not included in this repository by default. This avoids redistributing third-party material without first verifying the applicable permissions.
